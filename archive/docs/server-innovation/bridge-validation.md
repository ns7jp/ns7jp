## テストの扱い

テスト内のGitHub観測、台帳、実験条件は合成です。fetchは例外へ置き換え、CLIのデモはネットワークなしで実行します。
原本・モデル比較・未実施の区別を、生成した資料を単独で開いても確認できることを試験します。

レビューでは、同じ候補でHEADが進んだ場合の新しい登録下書きと、合成原本の由来表示を補いました。
元の下書きと途中の記録は保持し、新しい引き継ぎの比較元版と登録下書きのbaseline_shaが一致することを確認します。
負荷調整の確認待ちでは探索の登録簿を変更しないこと、モデル比較が始まる前の時間切れでは比較ケースを作成済みにしないことも確認しました。
