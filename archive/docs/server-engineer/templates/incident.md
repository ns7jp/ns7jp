# 障害対応記録（未記入の原本）

[育成システムへ戻る](../README.md)

障害を模擬するときは、使い捨てラボの対象・戻し方・観測項目を先に決めます。復旧を急いで推測を事実として書かないでください。

## 対象と影響

- 能力ID／試行ID:
- 対象・版・環境:
- 発生日時／検知日時:
- 影響を受ける操作・利用者:
- 影響を受けないと確認できた範囲:
- 復旧目標時間（RTO、事前に決める値）:
- 許容データ損失（RPO、事前に決める値）:
- 作業の中止・相談条件:
- 観察者／支援量:

## 復旧と測定

- 復旧操作と選んだ理由:
- サービス復旧時刻:
- 利用者操作まで回復した確認:
- 検知から復旧までの実測時間:
- 障害発生から復旧までの実測時間:
- 復元後のデータ件数・内容比較:
- 実際に失ったデータと時間範囲:
- RTO／RPO目標を満たしたか:
- ログの欠測、時刻ずれ、測定の限界:
- 再発防止案と未採用の案:
- 次回確認する要件・試験ID:

RTO／RPOは目標です。測定した時間や損失は実績として別欄に書きます。目標値を測定値へ書き換えず、未達も記録します。
