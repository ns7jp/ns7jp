# 終結・振り返り票テンプレート

[PJ07 終結・振り返り](../stages/07-closure.md) / [案件の入口](../README.md)

案件の非公開記録先に複製し、各担当が実際に確認した根拠を記録します。顧客の契約、請求、構成、ログ、秘密を公開リポジトリへ保存しません。

この票は法務・会計判断や削除許可を発行しません。金額は担当者の確認前には数値を入れず、未記入とします。実績・受領・支払・保存・アクセス終了は未確認または`NOT RUN`から始めます。

通常の全工程PASSによるCOMPLETEDと、取消によるCANCELLEDを区別します。未実施の工程をPASSで埋めて取消処理を完了させません。

範囲縮小に伴う作業のWITHDRAWNは、実施成功のDONEや案件全体のCANCELLEDと区別します。取り下げのsponsor確認・証跡、旧状態、影響工程の新しい条件記録と再承認を照合します。
