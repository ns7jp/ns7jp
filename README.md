## 社内ヘルプデスクに活かせる経験

**前職での棚卸し・Excel集計。** 倉庫では棚の商品と台帳を照合し、品番の表記をそろえました。出荷伝票をExcelのピボットテーブルで品番別・月別に集計し、よく出る商品を入口近くに移す案をまず棚1列で試しました。配置と補充手順を見直した結果、自分の在庫管理・ピッキング作業が1日約1時間短くなりました。[前職での改善と計測の範囲](./docs/business-improvement/picking-improvement.md)

**Windowsの共有ドライブが出てこないときに確かめたこと。** AIの案内を受けて自分で操作した個人実習です。設定が適用済みと表示されても、利用者の画面にドライブが現れませんでした。配布先のグループを示す欄が空だったため選び直し、設定の更新と再サインインを経て、共有ドライブからファイルを読めるところまで確認しました。[最初の失敗と再確認の記録](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-11-10-kvm-ad-client-access-gpo.md#部署別ドライブ配布と対象化の修正)

## 問い合わせ対応例「10時の打ち合わせで使う資料が開けません」

部署異動の直後に「アクセスが拒否されました」と表示された、という架空の相談です。AIの支援で作成した模擬チケットから、引き継ぎ時の返信を抜粋します。

> 10時の打ち合わせで資料を使うことを担当者に伝えました。異動に伴う利用申請と、現在の設定を照合してもらいます。確認が続いている場合も、9時30分までに私から状況をご連絡します。

引き継ぎメモには、同僚は同じフォルダを開けたことと、会議への影響を記録しました。最後に利用者から「これで打ち合わせの準備を続けられます」と返答を受けて、対応を終える例です。[最初の返信・引き継ぎメモ・完了記録](./docs/helpdesk-intake.md)
