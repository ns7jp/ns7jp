# 評価と記入テンプレート

[入口](README.md) / [能力設計](design.md) / [課題カード](practice.md)

本書は今回のBR/BX設計の記入枠です。既存SE条件は既存台帳・評価仕様を使います。BXを既存CLIへ直接入力しません。新規必須条件はNAで免除せず、実施困難ならBLOCKEDと代替計画を残します。以下のNA欄は任意観点の対象外理由にのみ使います。

この文書は、演習、設計、障害対応、復元、人のレビュー、引き渡しを同じ証跡でつなぐための記録用紙です。使う節だけをコピーし、`未確認` を確認した事実に置き換えてください。記録を埋めたことだけでは技能の合格になりません。

`BR0〜BR6` は橋渡し設計の見取り図、`BX01〜BX12` は追加課題です。既存の `SE00〜SE07`、PJ、Level の名称・要件・評価結果は上書きしません。既存段階に提出する場合は、その段階の正本にある条件IDと最新試行を対応付けます。対応が確認できなければ `未確認` のままにします。

結果は、①静的検査、②その試行の条件別結果、③提出物がそろった `READY FOR REVIEW`、④人の評価結果に分けて記録します。既存SEの段階PASSは既存仕様の用語です。BRは新しい段階PASSを生成せず、SEとBXの根拠から演習範囲の能力を説明します。評価者がいなくても練習、自己確認、補習、次の試行は続けられます。人の実技観察を要する最終評価だけを保留します。

支援量は既存方針に合わせて `guided`（手順例や人の助言）、`ai`（AIから操作手順や原因の答えを得た）、`independent`（公式資料・自分の手順書・man/helpを使い、自分で判断）を使います。AIで解けた試行を後から独力に変更せず、別の試行で確かめます。混在したら区間と内容を残し、答えを得た回を独力評価に使いません。
