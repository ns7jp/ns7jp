- `observed_at` / `completed_at`：GitHub取得を行った時刻。本人の成果確認日時ではありません。
- `verified_at`：繁栄評価器が受理できた上流観測の時刻。本人の理解や採用を認定する日時ではありません。
- `UNKNOWN`：必要な入力・確認が足りない状態。ゼロ、失敗、能力不足への置換をしません。
- `NOT_RUN`：対象の確認をまだ実施していない状態。設計・雛形・デモを実施記録に置換しません。
