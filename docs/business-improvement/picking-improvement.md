# 物流現場での業務改善｜棚と台帳の照合、新人向けの案内づくり

前職の物流倉庫で、在庫管理と、出荷する商品を棚から集めるピッキングを担当しました。棚の品番が古いままだと、新人はどこを探せばよいか分かりません。補充のタイミングも人によって違いました。そこで、棚の表示と配置、補充手順を見直し、新人が手元で確認できる地図とチェックリストを作りました。

<!-- markdownlint-disable-next-line MD033 -->
<a id="33-集計に使ったツール"></a>

## Excel でよく出る品番を調べ、棚と台帳を照合

自分の作業を1週間、15分単位で記録し、商品を探したり、在庫不足に対応したりする時間を上長に示しました。出荷伝票のデータは Excel にまとめ、ピボットテーブルで品番別・月別の出庫数を集計しました。

棚の商品と台帳を照合し、棚番号・品番・品名・最小在庫数を同じ形式で表示しました。よく出る商品を入口近くに移す変更は、まず1列で試してから他の棚にも広げました。補充の目安は倉庫の入口に掲示しました。

ハンディ端末で在庫不足を知らせる機能もIT担当に依頼しました。改修費用が課題となり、この要望は先送りになりました。

<!-- markdownlint-disable-next-line MD033 -->
<a id="44-新人向けマップチェックリスト"></a>

## 新人が商品を探すための地図とチェックリスト

- **場所マップ**　倉庫の平面図を商品の種類ごとに色分けし、よく出る品番を書き込みました。初めて担当する人も、探し始めるエリアを地図で確認できます。
- **作業チェックリスト**　初日、数日後、1週間目の順に、覚える作業をまとめました。新人がその日に確認する内容を見つけやすくするためです。

## 作業時間の変化

当時の作業記録では、在庫管理・ピッキングにかかる**自分の作業時間が1日あたり約1時間短くなりました**。元の時間記録は手元に残っていません。チーム全体の残業時間、ミス件数、新人が独り立ちするまでの日数は継続して計測していません。

## ヘルプデスク・IT事務で活かしたいこと

新人向けの地図に実際の品番を載せた経験から、ヘルプデスクでも、利用者が今どの画面を見ているかを聞き、そこに表示される名前を使って次の操作を案内したいです。IT事務では、棚と台帳を一つずつ照合した経験を、貸与端末の管理番号と資産台帳を照らし合わせる業務に活かしたいと考えています。
