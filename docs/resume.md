## 4. 活かせる経験・知識・スキル

前職で培った、**作業を計測する・上長へ改善を提案する・手順を標準化する**進め方を活かしたいと考えています。

個人学習では、AI の手順案内を受けて本人が VM を操作・確認しました。代表例は次のとおりです。

| 学習内容 | 本人が確認した結果・残る課題 |
| --- | --- |
| Ubuntu の初期構築・SSH 復旧 | 固定 IP・SSH 鍵認証・UFW 等を設定。意図的な設定不備を復元し、構文検査と鍵接続の成功を確認 |
| AD の構築・バックアップ復元 | 構築試験の必須31項目 PASS。復元後に目印の OU が消えることを確認したが、翌日 SYSVOL 欠損が判明。修正手順の実機検証は未完了 |
| WSUS の承認試験 | 分類・製品が0件のルールの適用範囲を調べ、手順を修正。0件になった操作は未特定、通し再試験は未実施で、判定は **FAIL** |

[日付・環境・結果票](./resume-evidence.md)と[原画像付きのLinux3事例](./evidence/featured-evidence.md)を掲載しています。構成の異なる演習は合算せず、本人による監視・実通知・復旧の一連の検証、長期稼働、別 VM 復元、AWS 実構築は未完了です。
