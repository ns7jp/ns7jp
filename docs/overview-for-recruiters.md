| **2. AD の構築・復旧** | 9/1〜4 に Windows Server 2022 で AD を構築し、必須 31 項目 PASS。DC 2 台での複製、System State 復元、1 台を失った想定での FSMO 役割の奪取まで実施しました。復旧全体は約 40 分で、起動設定の解除漏れによるやり直しも記録しています。[復元の記録](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-09-02-ad-restore-drill.md) |
| **3. WSUS の原因調査** | 9/7 の試験は必須 28 項目中 26 PASS、総合判定は **FAIL**。翌日、承認件数を照合して仮説を見直し、分類・製品 0 件のルールが全分類・全製品を対象にする仕組みを確認し、手順を修正しました。絞り込みが 0 件になった操作は未特定で、通しの再試験は未実施です。[調査の記録](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-09-08-wsus-sit04-sit06-root-cause.md) |
