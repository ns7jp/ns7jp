# 採用ご担当者さまへ — 島田則幸

**社内ヘルプデスクの一次対応を第一志望としています。** 物流現場では、新人が商品を探すときに迷う場所を地図にし、作業を覚えるためのチェックリストを作りました。IT サポートでも、利用者がどの作業で困っているかを聞き取り、ご本人が仕事を再開できたかを確かめる役割を担いたいと考えています。

## 一次対応の記入例

「10時の打ち合わせで使う資料が開けない」という架空の相談をチケットにまとめました。同じ部署の方は開けること、利用者の画面には「アクセスが拒否されました」と表示されることを記録し、権限担当に確認を依頼しています。利用者に約束した時刻の途中連絡と、資料を開けたという回答を受けて対応を終えるまでの文面も掲載しています。AI の支援で作成した記入例です。[共有フォルダの模擬チケット](./helpdesk-intake.md)
