## 対応漏れの確認

- [ ] 必須REQにDESとTESTがある。
- [ ] 実施済みとしたTESTに実在するEVIDがある。
- [ ] EVIDの対象環境・版・日時が試験記録と一致する。
- [ ] 要件に結び付かない設定変更を確認した。
- [ ] 廃止・変更は理由と合意版を残した。
- [ ] 未確認、欠測、FAIL、BLOCKED、NOT RUNを削除していない。
