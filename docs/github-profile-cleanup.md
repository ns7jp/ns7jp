## ピン留めで見せる順番

表示を組み直す場合の案は、**server → ns7jp.github.io → design → shell → network → aws** です。先頭の主作品で実行記録、続くサイトで全体像、副作品で設計・自動化・ネットワーク・クラウドの学習範囲を確認できます。`aws` は未検証範囲が説明文でも分かる状態で扱います。

これは配置案であり、現在のピン設定を確認した記録ではありません。採用担当者に見える画面で、先頭が主作品か、Description が表示されるか、各リンクが開くかを確認した後、[表示設定の記録](./github-profile-settings.md)へ日時と結果を残します。
