# 希望する仕事と関連する経験

第一志望は **社内ヘルプデスク・IT サポート**です。まずは、問い合わせを受けて業務への影響を聞き取り、手順に沿って確認し、担当者へ状況を引き継ぐ仕事を希望しています。PC キッティングや IT 事務、監視・運用の補助にも関心があります。利用者の業務とシステムの両方を知り、ゆくゆくは繰り返す問い合わせの原因を調べ、設定やアプリを改善できるようになりたいです。

## ヘルプデスクで活かしたい技術学習

- **Windows のユーザーと権限**　研修で利用者アカウントと権限の管理を学びました。個人実習では AI の案内で検証用アカウントの部署異動を試し、再サインイン後に新部署のファイルが読めることと、旧部署の共有先を直接指定すると拒否されることを確認しました。[部署異動の検証](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-11-10-kvm-ad-client-access-gpo.md#部署異動の検証)
- **サイトに接続できないときの切り分け**　机上演習で、利用者が通る入口とアプリ内部で違う結果が出る例を扱いました。測定は AI が担当し、私は結果を読んで次にどこを確認したいか回答しました。[測定結果と本人の回答](./practice-status.md#社内サイトが開けないときの確認)

IT の経験は研修と個人学習です。Linux・Windows Server の構築や監視については、学習した日付・環境・確認結果を別途記録しています。本人の操作、AI の案内、CI での実行の範囲も記載しています。[実習と技術経験の詳細](./resume-evidence.md) ／ [AI 支援の内訳](./ai-usage.md)
