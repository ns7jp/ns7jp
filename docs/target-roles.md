# 希望する仕事と関連する経験

第一志望は **社内ヘルプデスク・IT サポート**です。まずは、問い合わせを受けて業務への影響を聞き取り、手順に沿って確認し、担当者へ状況を引き継ぐ仕事を希望しています。PC キッティングや IT 事務の補助にも関心があります。

## 優先順位

| 希望する業務 | 関連する経験・公開資料 |
| --- | --- |
| 1. 社内ヘルプデスクの一次対応 | 共有フォルダが開けないという架空の問い合わせを題材に、最初の返信、影響範囲と期限の記録、権限担当への引き継ぎ、途中連絡、業務再開の確認をまとめました。AI の支援で作成した[模擬チケット](./helpdesk-intake.md)です。 |
| 2. PC キッティング・IT 事務の補助 | 前職では棚と台帳を照合し、表記をそろえ、新人用の場所マップとチェックリストを作りました。端末と資産台帳の照合や、初期設定後のチェックに活かしたい経験です。[物流現場での業務改善](./business-improvement/picking-improvement.md) |
| 関連業務　監視・運用の一次対応補助 | 個人の仮想環境で AI の手順案内を受け、Web サイトの入口を停止・復旧しました。利用者が通る入口を同じ VM から再び確認し、応答結果をもとに復旧を判断した理由を記録しました。[操作と本人の説明](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-11-06-nginx-guided-recovery.md) |

## ヘルプデスクで活かしたい技術学習

- **Windows のユーザーと権限**　研修で利用者アカウントと権限の管理を学びました。個人実習では AI の案内で検証用アカウントの部署異動を試し、再サインイン後に新部署のファイルが読めることと、旧部署の共有先を直接指定すると拒否されることを確認しました。[部署異動の検証](https://github.com/ns7jp/server/blob/main/docs/evidence/2026-11-10-kvm-ad-client-access-gpo.md#部署異動の検証)
- **サイトに接続できないときの切り分け**　机上演習で、利用者が通る入口とアプリ内部で違う結果が出る例を扱いました。測定は AI が担当し、私は結果を読んで次にどこを確認したいか回答しました。[測定結果と本人の回答](./practice-status.md#社内サイトが開けないときの確認)

IT の経験は研修と個人学習です。Linux・Windows Server の構築や監視については、学習した日付・環境・確認結果を別途記録しています。本人の操作、AI の案内、CI での実行の範囲も記載しています。[実習と技術経験の詳細](./resume-evidence.md) ／ [AI 支援の内訳](./ai-usage.md)
