# 第三者再現テスト記録

このテンプレートは、初心者向け教材の分かりやすさを感想ではなく実測で確認するために使います。個人名、IPアドレス、ユーザー名などの端末固有情報は公開しません。

## テスト情報

```text
テストID:
実施日:
事前経験:
利用 OS / バージョン:
PC のメモリ:
選択ルート（標準・軽量・基礎補習）:
対象ページ / Phase:
開始・終了時刻:
ヒント提供者:
```

## 結果

```text
ヒントなしで完了した項目数 / 全項目数:
30 分以上止まった箇所:
追加で質問した内容:
危険または曖昧だと感じた手順:
終了時に自分の言葉で説明できたこと:
完了できなかった項目:
```

## 停止箇所の詳細

| 手順 | 期待していたこと | 実際に起きたこと | 停止時間 | 必要だったヒント |
| --- | --- | --- | --- | --- |
| 例: 2-3 | SSH の状態確認 | `Unit ssh.service could not be found` | 35 分 | OpenSSH未導入の場合の分岐 |

## 教材への反映

```text
原因分類（教材の省略・環境差・前提知識・操作ミス）:
教材へ反映した修正:
修正したコミット / PR:
再テスト日:
再テスト結果:
```

## 完了条件

- [ ] 初学者2名以上の独立した記録がある
- [ ] 質問箇所、停止箇所、完了率、所要時間が記録されている
- [ ] 同じ停止箇所が2名にあれば教材を修正した
- [ ] 修正後に同じ条件で再テストした
- [ ] 個人情報と秘密情報を公開していない
