# 今後の興味リスト（中長期・未着手）

> **本ドキュメントの位置付け**
>
> 実装・実機検証が一切ない中長期テーマの一覧です。以前はテーマごとに個別の設計書（10 本、
> 合計約 2,800 行）を保管していましたが、実装が伴わないまま設計だけが積み上がると、
> 未経験者としての実際のスキル水準に対して範囲が広すぎるという判断から、2026-08-26 に
> 個別の設計書をすべて削除し、方向性だけを示す短い一覧に集約しました。設計を捨てたのでは
> なく、露出の量を実際の到達度に合わせています。

## 一覧

いずれも実装・実機検証は未着手です。着手した際は、[server-monitor 改善設計](../server-monitor-improvements/README.md) 側の一次導線へ改めて追加します。
